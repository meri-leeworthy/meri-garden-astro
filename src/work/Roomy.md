I work as a core engineer on Roomy, a group messaging platform designed for organisations and communities that prioritises user autonomy and effective knowledge management. Since May 2024, I've been responsible for both application-level features and significant contributions to the underlying infrastructure.

My work includes substantial development on Leaf, the lightweight event-sourcing protocol and server that powers Roomy's real-time messaging and data persistence layer. This involved designing and implementing core architectural patterns that enable reliable, scalable message distribution while maintaining a clean separation between the protocol layer and application logic.

Key contributions include:
- Architecting and implementing features for the Leaf event-sourcing engine
- Building frontend features that leverage real-time data synchronization
- Performance optimisation across the full stack
- Contributing to protocol design decisions that affect data consistency and reliability

The role requires deep engagement with distributed systems concepts, balancing the needs of a production application with ongoing protocol evolution.
